# 出门用手机上课：Chrome 远程桌面

**原理**：程序还在家里电脑上跑，手机只是"看"电脑屏幕、把你的手指点击传回电脑。
所以家里电脑必须开着，手机要能上网（Wi‑Fi 或流量都行）。
不需要改路由器、不需要公网 IP：连接由 Google 的服务器中转。

## 一次性设置（在家里电脑上，约 10 分钟）

1. 用 Chrome 打开 <https://remotedesktop.google.com/access>，登录你的 Google 账号。
2. 点"设置远程访问"→ 下载并安装主机程序（Chrome Remote Desktop Host）。
3. 给这台电脑起个名字，设一个**至少 6 位的 PIN 码**（以后在手机上连接时要输入）。
4. 防止电脑睡着：Windows 设置 → 系统 → 电源 → "接通电源后，电脑在此时间后进入睡眠状态"改成**从不**。
   屏幕可以关，电脑不能睡。

## 手机上

1. 应用商店搜索 "Chrome Remote Desktop"（Chrome 远程桌面）安装，登录**同一个** Google 账号。
2. 列表里点你的电脑，输入 PIN，就能看到家里电脑的桌面。
3. 双击桌面上的 `Start-MCU3D.bat` 启动课程（建议把手机横过来）。
4. 点右下角 **"屏幕按键"**：底部会出现这一课能用的按键（空格、T、Backspace……）和通用按键（讲解翻页、放大缩小、菜单），直接点，不用调出手机键盘。

## 手机上的手势（Chrome 远程桌面默认是"触控板模式"）

- 单指拖动：移动鼠标指针；单指轻点：左键单击
- 双指轻点：右键；双指拖动：滚动
- 双指捏合：放大手机上的画面（只是看得更清楚，不影响程序）
- 在菜单里可以切到"触摸模式"：手指点哪里就点哪里，更直观

电路图里"双击进入下一层"：触摸模式下在同一个位置快速点两下；也可以先单击选中，再点屏幕按键里的 **Enter 进入**。

## 什么时候会用不了

- 家里电脑关机、睡眠、断网、或 Windows 自动更新重启了。
- 手机信号差：画面会卡、变糊，操作会延迟。
- 有些公司、学校的网络会屏蔽远程桌面类软件。
- 每小时大概会用掉几百 MB 流量（粗略估计，和画质、画面变化多少有关），用流量时注意。

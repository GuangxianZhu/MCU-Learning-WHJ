# MCU 零基础入门 · 课程大纲

> 适合：完全没接触过单片机、电路和底层编程的同学。
> 方法：每一课先在 3D 课堂里“看见”芯片内部发生了什么，再读本页的要点和小练习。
> 打开 3D 课堂：`python -m mcu3d`（直接进入第 N 课：`python -m mcu3d N`）。
> 任何一课按 `S` 打开“芯片内部模拟器”：CPU 真的一条一条执行机器码。

## 第 1 课　什么是 MCU ✅

**目标**：知道 MCU 是什么、长什么样、用在哪里。

- MCU = Micro Controller Unit，微控制器，俗称“单片机”。
- 一颗 MCU = CPU（大脑）+ Flash（存程序）+ SRAM（存数据）+ 外设（手和眼睛），全部在一颗芯片里。
- 引脚（Pin）是 MCU 与外界交流的唯一通道；黑色外壳叫封装，里面是硅晶片（Die）。
- 与电脑 CPU 对比：频率低、内存小、不需要操作系统、便宜、省电。
- 3D 演示：空格逐步讲解，点击芯片揭开外壳，最后看 LED 闪烁。

**小练习**：找一找家里有哪些电器里可能藏着 MCU（提示：带按键和指示灯的大多都有）。

## 第 2 课　二进制与寄存器 ✅

**目标**：会看二进制、十六进制，理解寄存器和位操作。

- 位（bit）只有 0 和 1；8 位 = 1 字节（Byte），能表示 0~255。
- 权重：从右往左 1、2、4、8、16、32、64、128。
- 十六进制：每 4 位对应一个 0~F，`1010 0011` = `0xA3`。
- 寄存器：芯片里的一排“小格子”，外设寄存器的每一位往往对应一个开关。
- C 语言位操作：`|=` 置 1、`&= ~` 清 0、`^=` 翻转、`<<` `>>` 移位。
- 3D 演示：按 1~8 翻转各位，空格加 1，左右方向键移位，A 自动计数。

**小练习**：把 200 写成二进制和十六进制；`reg = 0x0F; reg |= (1 << 7);` 之后 reg 等于多少？

## 第 3 课　存储器与地址 ✅（模拟器）

**目标**：知道变量、程序各住在哪个地址。

- 存储器 = 一排带编号的格子，每格 1 字节，编号就是地址；32 位 CPU 一次读写 4 字节（一个字）。
- 内存映射：Flash 0x0800 0000 起（向量表 + 机器码 + 文字池），SRAM 0x2000 0000 起（变量、栈），外设 0x4000 0000 起。
- 例程：`int a = 5, b = 7, c; c = a + b;`，a、b、c 在 0x2000 0000 / 04 / 08。
- 学了能做什么：看懂存储器映射图，用调试器内存窗口查变量。

**小练习**：再加一个变量 d，它的地址最可能是多少？

## 第 4 课　总线：一次读和一次写 ✅（模拟器）

**目标**：理解地址线、数据线、读/写线如何配合。

- 读：CPU 放地址、读写线 = 读 → 地址译码找到模块 → 模块把数据放上数据线。
- 写：CPU 放地址和数据、读写线 = 写 → 模块存下数据。取指也是一次读。
- 例程：`b = a; a = 0;`，`LDR R2, =a` 还要从 Flash 文字池读一次。

**小练习**：执行完 `b = a;`（3 条指令）总线一共用了几次？几次读、几次写？

## 第 5 课　CPU 内部：取指、译码、执行 ✅（模拟器）

**目标**：看懂寄存器组、PC，以及一条指令的执行过程。

- 循环：取指（PC+2）→ 译码 → 执行（读寄存器、ALU、访存）→ 写回。
- R0~R12 通用寄存器，SP 栈指针，LR 返回地址，PC 下一条指令地址。
- C → 汇编 → 机器码：`a = a + 1;` = `LDR / ADDS / STR`；`ADDS R0, R0, #1` = `1C40`，逐段拆开。

**小练习**：改成加 2，机器码是多少？

## 第 6 课　ALU 与标志位 ✅（模拟器）

**目标**：理解二进制加法、补码、NZCV，以及 if / while 的实现。

- ALU 一位一位相加，进位传给高位；减法 = 加上“取反再加 1”。
- N 负、Z 零、C 进位、V 有符号溢出。
- `if (t > 30)` = `CMP R0, #30` + `BLE`；例程 2 演示 0-1、进位、溢出。

**小练习**：t 从 24 每圈加 3，第几圈开始报警？

## 第 7 课　函数调用与栈 ✅（模拟器）

**目标**：理解 BL / LR / PUSH / POP 和栈。

- 参数 R0~R3，返回值 R0；BL 把返回地址存进 LR，BX LR 返回。
- 还要调别人的函数先 `PUSH {R4, LR}`，结束 `POP {R4, PC}`；栈从 0x2000 5000 往低地址长。
- 第 10 课中断时，硬件也会自动把寄存器压栈。

**小练习**：第一次进入 add 时 SP 是多少？栈里有什么？

## 第 8 课　GPIO 输入输出 ✅

**目标**：理解“写寄存器点灯、读寄存器知道按键”。

- 输出：向 ODR 某一位写 1 → 引脚 3.3V（高电平）→ LED 亮。
- 输入：引脚电压记录到 IDR，程序读取即可得知按键状态。
- 引脚命名：PA0~PA15、PB0…（端口 + 编号）；真实芯片还需先配置模式寄存器（MODER）、开启时钟。
- 经典程序：流水灯、按键控制、二进制计数。
- 3D 演示：1~8 控制 PA0~PA7，按住 B 模拟按键，空格切换不同程序并查看对应 C 代码。

**小练习**：写出“只让 PA0 和 PA7 亮”的 ODR 值（十六进制）。

## 第 9 课　定时器与 PWM ✅

**目标**：会算定时时间，理解占空比。

- 计数器 CNT 跟随时钟（经预分频 PSC）不断加 1，到 ARR 归零并产生更新事件（可触发中断）。
- 定时时间 = (PSC+1) × (ARR+1) ÷ 时钟频率。
- PWM：CNT < CCR 输出高，否则输出低；占空比 = CCR ÷ (ARR+1)，决定 LED 亮度、电机转速。
- 3D 演示：空格切换“定时中断 / PWM”，上下方向键调 ARR 或 CCR，F 切换慢速与真实速度。

**小练习**：72MHz 时钟，想要每 0.5 秒中断一次，PSC 取 7199 时 ARR 应该是多少？

## 第 10 课　时钟与中断 ✅

**目标**：理解时钟是节拍、中断是“先处理急事”。

- 晶振产生方波，每个上升沿是一拍；频率越高执行越快。
- 中断：外设发出请求 → CPU 执行完当前指令 → 保存现场（压栈）→ 执行中断服务函数 ISR → 恢复现场 → 回到原处。
- 轮询 vs 中断：轮询要一直问，中断像门铃。
- 3D 演示：空格按下按键触发中断，观察 PC 指针跳转、栈的压入弹出；上下方向键调节时钟快慢。

**小练习**：如果中断服务函数里写了一个很长的延时，会发生什么问题？

## 第 11 课　UART 串口通信 ✅

**目标**：理解串行通信、帧格式和波特率，知道 UART 外设内部由哪些部分组成。

- 位置：UART 外设；TX、RX 是借给它用的两个 GPIO 引脚。
- 三根线：TX、RX、GND；A 的 TX 接 B 的 RX。
- UART 内部组成：
  - TDR 发送数据寄存器：CPU 把要发的字节写到这里
  - 发送移位寄存器：从 TDR 整体搬入，每个节拍往外挤出一位
  - 波特率发生器：把系统时钟分频成每一位的节拍
  - 接收移位寄存器：每个节拍收进一位，攒满 8 位
  - RDR 接收数据寄存器：收满的字节放在这里等 CPU 读
  - 状态寄存器：TXE（TDR 空，可以写下一个）、RXNE（RDR 有新数据）
- 帧格式：空闲高电平 → 起始位 0 → 8 个数据位（低位先发）→ 停止位 1。
- 波特率：每秒传输的位数，双方必须一致（常用 9600、115200）。
- ASCII：字符用数字表示，'A' = 65 = 0x41。
- 3D 演示：键盘打字后，按 8 个步骤观察：CPU 写 TDR → 搬进移位寄存器 → 一位一位挤到 TX 线 → B 的移位寄存器逐位收进 → 搬进 RDR、RXNE 置 1 → CPU 读走。

**小练习**：画出发送字符 'C'（ASCII 67）时 TX 线上的完整波形。

## 第 12 课　I2C 与 SPI ✅

**目标**：理解“同步串行总线”，会区分 I2C 和 SPI。

- 位置：I2C / SPI 外设，以及借给它们的 GPIO 引脚。
- I2C：两根线（SCL 时钟、SDA 数据），靠 7 位设备地址选设备，一条总线可挂多个设备；
  通信过程：起始 → 地址 + 读/写 → 应答 ACK → 数据 → 应答 → 停止。线上需要上拉电阻。
- SPI：SCK、MOSI、MISO 加每个设备一根 CS 片选；不用地址，拉低谁的 CS 就和谁说话；全双工、速度快。
- 与 UART 的区别：有时钟线（同步）vs 没有时钟线（异步）；一主多从 vs 一对一。
- 3D 演示：按 M 切换 I2C / SPI。I2C 里读温度传感器、写屏幕、写 EEPROM，还可以喊一个不存在的地址看 NACK；SPI 里观察片选和 MOSI/MISO 同时传输。

**小练习**：I2C 总线上有地址 0x48 的设备，主机要读它，第一个字节应该发什么（二进制）？

## 第 13 课　ADC 模数转换 ✅

**目标**：理解采样与量化，会在读数和电压之间换算。

- 位置：ADC 外设，结果在 ADC 数据寄存器 ADC_DR 里。
- 把 0~3.3V 的连续电压变成数字：n 位 ADC 有 2ⁿ 个台阶（12 位 = 0~4095）。
- 读数 = 电压 ÷ 3.3V × (2ⁿ - 1)；电压 = 读数 ÷ (2ⁿ - 1) × 3.3V。
- 位数越多越精细，采样越快越接近真实曲线。
- 3D 演示：转动电位器，看真实电压曲线和 ADC 台阶；切换 3/4/8/12 位、调采样速度，LED 亮度跟随读数。

**小练习**：12 位 ADC 读到 1241，电压大约是多少？

## 第 14 课　综合项目：温度报警器 ✅

**目标**：把前面学过的所有外设串起来，理解一个完整 MCU 程序的结构。

- 流程：定时器中断（每 0.5 秒）→ ADC 读传感器电压 → 换算温度 → 和阈值比较 → GPIO 控制红/绿灯、PWM 驱动蜂鸣器 → UART 把温度发给电脑。
- 3D 演示：按住 H 给传感器加热，看温度上升、超过阈值后报警；上下方向键调阈值；电脑屏幕上滚动显示串口收到的温度。讲解面板里有完整的 C 程序（简化版）。

**小练习**：如果想让报警时蜂鸣器“嘀—嘀—”地响而不是一直响，程序要怎么改？
